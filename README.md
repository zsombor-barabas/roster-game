# Roster Game

A systems-focused game built with Godot 4 and typed GDScript.

The initial development phase will use simple placeholder visuals to validate the core gameplay before production artwork is introduced.

## Repository layout

- [`game/`](game/) — the Godot project: source code, scenes, assets, and game-specific configuration.
- [`vault/`](vault/) — working notes, brainstorming, sketches, and other project material that does not fit well in Notion.

The Godot project will live in `game/`. Keep the vault free of generated builds and large temporary exports.
